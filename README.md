# my-diary

ไดอารี่ส่วนตัว — เว็บแอปแบบ local-first เขียนได้หลายรอบต่อวัน พร้อมโมดูลการเงิน/ทรัพย์สิน/หนี้สินในตัว

**ฟีเจอร์หลัก — ไดอารี่**
- โหมดบันทึกส่วนตัวแบบเข้ารหัส (AES-256-GCM) ต่อ entry พร้อมคำใบ้รหัสผ่านและตัวรีเซ็ตรหัสผ่าน
- แนบรูปภาพ, บันทึกเสียง, วิดีโอสั้น (สูงสุด 30 วิ), วาดภาพ (sketch pad พร้อม undo/ยางลบ), แนบไฟล์ PDF/text (สูงสุด 10MB/ไฟล์ — เก็บไว้ให้ดาวน์โหลดเฉยๆ ไม่แสดงเนื้อหาในตัวบันทึก)
- จัดรูปแบบข้อความ: **ตัวหนา**, *ตัวเอียง*, บูลเล็ต, เช็คลิสต์ (แตะเพื่อติ๊กได้จริง), คำพูดอ้างอิง, โค้ดบล็อก (มีปุ่มคัดลอก, ยุบอัตโนมัติถ้ายาว), ลิงก์กดได้อัตโนมัติ, แทรกอีโมจิด่วน
- บันทึกตำแหน่ง GPS แบบไม่บังคับ (ละเอียดถึงระดับอาคาร/ชื่อร้านถ้ามีติดแท็กใน OpenStreetMap) พร้อมสภาพอากาศ ณ ตอนนั้น (อุณหภูมิ/สภาพอากาศ/ความชื้น จาก Open-Meteo) และลิงก์เปิด Google Maps
- ปักหมุดบันทึกสำคัญ (📌 = เหตุการณ์สำคัญ, ติ๊กได้ตั้งแต่ตอนเขียน), ติดสีป้ายพาสเทล, ค้นหา/กรองตามแท็กและเดือน, ปฏิทินดูภาพรวม
- **Timeline View** — เส้นเวลาแนวตั้งของทุกบันทึก แบ่งพับตามเดือน (เดือนล่าสุดเปิดอัตโนมัติ เดือนอื่นพับไว้ แตะเพื่อขยาย) รายการที่ปักหมุดไว้ไฮไลต์เด่นด้วยจุดสีทอง
- "วันนี้ในอดีต" และแบนเนอร์เตือนถ้ายังไม่ได้เขียนวันนี้
- Auto-save ร่างระหว่างเขียน (ยกเว้นบันทึกส่วนตัว เพื่อไม่ให้เก็บข้อความไม่เข้ารหัสไว้)
- หน้าสถิติ/ภาพรวม — จำนวนบันทึก, สตรีกการเขียน, อารมณ์/แท็กที่พบบ่อย
- ถังขยะ — ลบแล้วกู้คืนได้ (ปรับได้ 7/14/30/60/90 วัน ในตั้งค่า) ก่อนลบถาวรอัตโนมัติ พร้อมเตือนล่วงหน้าถ้าใกล้ครบกำหนด (ลบถาวรแล้วซิงค์ไม่ดึงกลับมา)
- ธีม 7 แบบ + ปรับขนาดตัวอักษรได้ ในหน้าตั้งค่า, ล็อกอัตโนมัติเมื่อไม่ได้ใช้งาน (ตั้งเวลาได้)
- รับข้อความ/ลิงก์จากแอปอื่นผ่าน "แชร์เข้า" และแชร์บันทึกออกเป็นข้อความ (Web Share API)
- **แจ้งเตือนอัปเดตแอป** — เช็คเวอร์ชันใหม่อัตโนมัติทุกครั้งที่เปิดแอป ขึ้นแบนเนอร์ให้กดโหลดใหม่ทันทีที่เจอ ไม่ต้องรีเฟรชเดามือเอง

**ฟีเจอร์หลัก — การเงิน**
- **รายรับ-รายจ่าย-โอนเงิน** — แยกหมวดหมู่และกระเป๋าเงินได้เอง รองรับสกุลเงิน USD (ใส่อัตราแลกเปลี่ยนเอง หรือให้ระบบดึงอัตโนมัติ) ยอดคงเหลือต่อกระเป๋า สรุปเดือนนี้ กราฟรายเดือน+แยกหมวดหมู่ ตารางสรุปย้อนหลัง 6 เดือน ค้นหา/กรองรายการได้ รายการแบ่งกลุ่มตามวันที่ แนบรูปใบเสร็จได้ (บีบอัดอัตโนมัติ, sync ขึ้น Google Drive ด้วย)
- **บัญชีธนาคาร** — ชื่อ/เลขบัญชี/เจ้าของบัญชี/ประเภทบัญชี/สาขา/หมายเหตุ, โลโก้ธนาคารไทย 20 แบงก์ (จับคู่อัตโนมัติจากชื่อที่พิมพ์, เลือกเองได้, หรืออัปโหลดโลโก้เองก็ได้), ปักหมุดบัญชีที่ใช้บ่อยให้ขึ้นบนสุด+โชว์ในหน้าแรก, ส่งสรุปยอดเข้า Telegram รายบัญชีได้
- **หนี้สิน** — ยอดกู้/คงเหลือ/ค่างวด/วันชำระ/วงเงินคงเหลือ (สำหรับสินเชื่อ/บัตรกดเงินสด), progress bar สีไล่แดง→เขียวตามเปอร์เซ็นต์ผ่อน, ป้ายเตือน "ใกล้ครบกำหนดชำระ" เด่นต่อรายการ (ตั้งจำนวนวันล่วงหน้าเองได้ในตั้งค่า), แบนเนอร์เตือนที่หน้าแรกอัตโนมัติ, หนี้ที่ใกล้ครบกำหนดจะเรียงขึ้นบนสุดของลิสต์เสมอ
- **ข้อมูลอื่นๆ** — เก็บข้อมูลอิสระแบบ key/value เช่น เลขกรมธรรม์ประกัน, เลขสมาชิก ฯลฯ ตั้งหมวดหมู่เอง
- **⚠️ บัญชีธนาคาร/หนี้สิน/ข้อมูลอื่นๆ ไม่เข้ารหัสเลย** (ต่างจากบันทึกไดอารี่ส่วนตัวที่ยังเข้ารหัสอยู่) — เป็นการตัดสินใจตั้งใจเพื่อตัดปัญหาเรื่องปลดล็อก/ถอดรหัสไม่สำเร็จทิ้งไปทั้งหมด ถ้าใครก็ตามเปิดเครื่อง/แอปได้ จะเห็นข้อมูลพวกนี้ได้เลยไม่ต้องใส่รหัส
- **Statement** — export รายการธุรกรรมทุกกระเป๋ารวมกัน เรียงตามเวลาจริง เลือกช่วงวันที่เอง (มีปุ่มลัด 7/30/90 วัน/1 ปี) ออกได้ 4 แบบ: ดาวน์โหลด CSV, ดาวน์โหลด PDF (ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์), ส่ง CSV เข้า Telegram, ส่ง PDF เข้า Telegram (ฝังฟอนต์ไทยในตัว โหลดไลบรารีเสริมตอนใช้ครั้งแรกเท่านั้น)
- **แนวโน้มมูลค่าสุทธิ** — กราฟเส้น SVG (ไม่พึ่งไลบรารีภายนอก) ของเงินสด+บัญชีธนาคารรวมกันตามช่วงเวลา คำนวณจากประวัติธุรกรรมจริง (ไม่รวมทรัพย์สิน เพราะไม่มีประวัติราคาย้อนหลังให้คำนวณแม่นได้) แตะดูค่าที่จุดต่างๆ ได้

**ฟีเจอร์หลัก — ทรัพย์สิน/อื่นๆ**
- **โมดูลทรัพย์สิน** — บันทึกหุ้น/ETF/คริปโต/ทอง/ของมีค่า คำนวณกำไร-ขาดทุนอัตโนมัติ มูลค่าปัจจุบันอัปเดตเอง (ปุ่มอัปเดตด่วนไม่ต้องเปิดฟอร์มเต็ม) กราฟสัดส่วนพอร์ตตามประเภท
- **เหตุการณ์ (Event)** — Entry อีกประเภทหนึ่งแยกจากไดอารี่ปกติ (ใช้ระบบแนบไฟล์/GPS/วันเวลาเดียวกันทั้งหมด) เลือกหมวดเหตุการณ์ได้เอง ผูกกับรายการเงินในวันเดียวกันได้ถ้ามี (สร้างรายการเงินใหม่จากในฟอร์มได้เลย) กรองดูเฉพาะไดอารี่/เหตุการณ์ได้ในแท็บ Diary
- **อัตราแลกเปลี่ยน USD/THB** — ดึงอัตโนมัติเมื่อเปิดแอป (ถ้าข้อมูลเก่าเกิน 8 ชม.) โชว์ในตั้งค่าและในฟอร์มที่เกี่ยวข้อง รีเฟรชเองได้
- **ส่งเข้า Telegram** — บันทึกไดอารี่/เหตุการณ์และรายการเงินที่ไม่ใช่ส่วนตัวส่งเข้ากลุ่ม Telegram อัตโนมัติทุกครั้งที่สร้างใหม่ (ปิดแยกเฉพาะรายการเงินได้), ส่งย้อนหลังบันทึกเก่าทั้งหมดได้เป็นชุด, ส่งสรุปการเงินทั้งหมด (กระเป๋าเงิน+ทรัพย์สิน+หนี้สิน+มูลค่าสุทธิ) แบบกดเองได้ — บันทึกส่วนตัวไม่ถูกส่งเด็ดขาดไม่ว่ากรณีใด
- **แกลเลอรีไฟล์แนบ** — รวมรูป/เสียง/วิดีโอ/ภาพวาด/ไฟล์ PDF-text จากทุกบันทึก (ไม่รวมส่วนตัว) กรองตามประเภท เรียงลำดับได้หลายแบบ (วันที่/ขนาดไฟล์/ประเภท, มาก↔น้อย) เลือกหลายไฟล์ดาวน์โหลดพร้อมกัน หรือ**ลบทิ้งถาวร**ได้เลย (ลบออกจากบันทึกที่แนบไว้ด้วย ไม่มีถังขยะสำหรับไฟล์แนบ)
- **ความทนทานของข้อมูล** — ขอสิทธิ์กันเบราว์เซอร์ล้างข้อมูลอัตโนมัติ (persistent storage), โชว์พื้นที่ที่ใช้ไปในตั้งค่า, เตือนถ้าไม่ได้ซิงค์ Google Drive เกิน 7 วัน, ปุ่มรีเซ็ตการเชื่อมต่อ Google Drive ถ้าซิงค์ผิดบัญชี/มีปัญหา
- เวอร์ชันแอปโชว์ที่ header ตลอดเวลา เช็คได้ไวไม่ต้องเข้าตั้งค่า

ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ ผ่านเบราว์เซอร์ปกติ หรือติดตั้งเป็นแอป (Add to Home Screen) เพราะเป็น PWA

## เก็บข้อมูลไว้ที่ไหน

ข้อมูลทั้งหมดเก็บอยู่ใน **IndexedDB ของเบราว์เซอร์** บนเครื่องที่เปิดใช้งาน (ข้อความ + ไฟล์แนบ + ข้อมูลการเงินทั้งหมด) ไม่มีการส่งข้อมูลไปที่ไหนโดยอัตโนมัติ โค้ดใน repo นี้ไม่มีเนื้อหาไดอารี่/ข้อมูลการเงินของใครทั้งสิ้น — ไฟล์สำรอง (`diary-backup-*.json`, `diary-entry-*.json`) ถูกกันไว้ใน `.gitignore` ไม่ให้หลุดขึ้น repo โดยไม่ตั้งใจ

**บันทึกส่วนตัว (🔒)**: เนื้อหา + ไฟล์แนบทั้งหมดเข้ารหัสรวมอยู่ในก้อนเดียว ด้วยกุญแจที่มาจากรหัสผ่านที่ตั้งไว้ (ไม่เคยถูกเก็บ) — PBKDF2 (150,000 รอบ, SHA-256) + AES-256-GCM ผ่าน Web Crypto API ของเบราว์เซอร์เอง

**บันทึกทั่วไป**: ไฟล์แนบ (รูป/เสียง/วิดีโอ/ภาพวาด/PDF-text) เก็บแยกเป็น attachment ใน IndexedDB และเมื่อซิงค์ จะอัปโหลดเป็นไฟล์แยกบน Google Drive ของคุณเอง (มองเห็นเฉพาะไฟล์ที่แอปนี้สร้าง เพราะขอสิทธิ์แบบ `drive.file`) — ทำให้เปิดจากอีกเครื่องแล้วดึงไฟล์แนบมาได้ตามต้องการ (lazy download) รวมถึงรูปใบเสร็จของธุรกรรมด้วย

**ข้อมูลการเงิน (บัญชีธนาคาร/หนี้สิน/ข้อมูลอื่นๆ)**: **ไม่เข้ารหัสเลย** เก็บเป็นข้อความปกติใน IndexedDB — ตัดสินใจแบบนี้โดยตั้งใจเพื่อตัดปัญหาเรื่องปลดล็อก/ถอดรหัสไม่สำเร็จ ถ้าต้องการความเป็นส่วนตัวสำหรับข้อมูลกลุ่มนี้ ควรตั้งรหัสล็อกหน้าจอ/แอปในระดับระบบปฏิบัติการแทน

## เปิดใช้งานผ่าน GitHub Pages

1. Push โค้ดนี้ขึ้น repository บน GitHub (repo ชื่อ `my-diary`)
2. ไปที่ repo → **Settings → Pages**
3. ใต้ "Build and deployment" เลือก Source: **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ GitHub จะให้ URL ประมาณ `https://<username>.github.io/my-diary/`
6. เปิด URL นั้นบนมือถือ/คอมพิวเตอร์ แล้วกด "Add to Home Screen" (มือถือ) หรือติดตั้งผ่านไอคอนติดตั้งในแถบที่อยู่ (คอมพิวเตอร์) เพื่อใช้งานแบบแอป — ถ้าเคยติดตั้งไว้แล้วก่อนอัปเดตนี้ ให้ลบแอปเดิมออกแล้วติดตั้งใหม่ เพื่อให้ฟีเจอร์ "แชร์เข้าไดอารี่" ทำงาน (share_target ต้องติดตั้งใหม่ถึงจะรู้จัก)
7. ถ้าเปิดแอปแล้วเวอร์ชันไม่ยอมขยับหลังอัปเดตโค้ด ให้ลองรีเฟรช 2 ครั้งก่อน — ถ้ายังไม่ได้ ใช้ปุ่ม "รีเซ็ตการเชื่อมต่อ" ไม่ได้ (นั่นคือ Google Drive) ให้ล้าง cache ของเว็บนี้ผ่านตั้งค่าเบราว์เซอร์แทน (ไม่กระทบข้อมูลใน IndexedDB)

## ตั้งค่า Google Drive Sync

ต้องสร้าง OAuth Client ID ของตัวเองใน Google Cloud Console (ฟรี) แล้วนำมาใส่ใน `js/drive-config.js`:

1. https://console.cloud.google.com/ → สร้างโปรเจกต์ใหม่
2. เปิดใช้งาน **Google Drive API** (APIs & Services → Library)
3. ไปที่ **Google Auth Platform** (เมนูใหม่แทน "OAuth consent screen" เดิม) → Get started → เลือก Audience: **External**
4. แท็บ **Audience** → เพิ่มตัวเองเป็น Test user
5. แท็บ **Data Access** → เพิ่ม scope `.../auth/drive.file`
6. แท็บ **Clients** → Create OAuth client → Web application → Authorized JavaScript origin ใส่ URL ของเว็บนี้ (เช่น `https://<username>.github.io`, ห้ามมี path ต่อท้าย)
7. คัดลอก Client ID มาวางแทนที่ `PASTE_YOUR_CLIENT_ID_HERE...` ใน `js/drive-config.js`
8. Push ขึ้น GitHub อีกครั้ง แล้วรีเฟรชหน้าเว็บ 2 ครั้ง (service worker ต้องอัปเดตตัวเองก่อน)

กดปุ่ม "ซิงค์ตอนนี้" ในหน้าตั้งค่าเพื่อรวมข้อมูล+ไฟล์แนบระหว่างเครื่อง — ถ้าซิงค์ผิดบัญชี Google หรือมีปัญหา (เช่นมีหลายบัญชีในเครื่อง) ใช้ปุ่ม "รีเซ็ตการเชื่อมต่อ" ข้างๆ กัน เพื่อบังคับให้เลือกบัญชีใหม่รอบหน้า — ไม่ลบข้อมูลใดๆ ทั้งในเครื่องและใน Drive

## ตั้งค่าส่งเข้า Telegram

ไม่ต้องแก้โค้ด ตั้งค่าได้ในแอปโดยตรง (ตั้งค่า → Telegram):

1. เปิดแชทกับ **@BotFather** ใน Telegram → `/newbot` → ตั้งชื่อบอท → ได้ **Bot Token** มา
2. สร้างกลุ่มใหม่ → เชิญคนที่อยากให้เห็น + เชิญบอทเข้ากลุ่มด้วย
3. ส่งข้อความอะไรก็ได้ในกลุ่ม 1 ข้อความ แล้วเปิด `https://api.telegram.org/bot<TOKEN>/getUpdates` ในเบราว์เซอร์ (แทน `<TOKEN>` ด้วยของจริง) หา `"chat":{"id":-100xxxxxxxxxx}` — เลขนั้นคือ **Chat ID**
4. ใส่ Token + Chat ID ในแอป → บันทึก → กด "ทดสอบส่งข้อความ"

บันทึกไดอารี่/เหตุการณ์และรายการเงินที่ไม่ใช่ส่วนตัวจะส่งเข้ากลุ่มอัตโนมัติทุกครั้งที่สร้างใหม่ (ปิดเฉพาะรายการเงินได้ในตั้งค่า) — บันทึกส่วนตัวไม่ถูกส่งเด็ดขาด

## โครงสร้างไฟล์

```
index.html          หน้าหลัก
css/style.css        ธีม/สไตล์ (7 ธีม + ปรับขนาดตัวอักษร)
js/app.js            ตรรกะหลักของแอป (ไดอารี่, Timeline View, หน้าแรก, ตั้งค่า, backup/restore)
js/db.js             ชั้นเก็บข้อมูล (IndexedDB: entries, attachments, transactions, assets, bank_accounts, debts, other_info)
js/crypto.js          เข้ารหัส/ถอดรหัสบันทึกส่วนตัว (Web Crypto API)
js/markdown.js        จัดรูปแบบข้อความเบาๆ + เช็คลิสต์
js/theme.js           ธีม/ขนาดตัวอักษร
js/exchange.js        อัตราแลกเปลี่ยน USD/THB (อัปเดตอัตโนมัติเมื่อเปิดแอป ถ้าข้อมูลเก่าเกิน 8 ชม.)
js/finance.js         โมดูลการเงิน (รายรับ/รายจ่าย/โอนเงิน, ระบบ "แหล่งเงิน")
js/banking.js         โมดูล Banking & Liabilities (บัญชีธนาคาร/หนี้สิน/ข้อมูลอื่นๆ — ไม่เข้ารหัส)
js/bank-logos.js      โลโก้ธนาคารไทย 20 แบงก์ + ตัวจับคู่ชื่อภาษาไทย/อังกฤษ
js/statement.js       ส่งออก Statement (CSV/PDF/Telegram)
js/nettrend.js        กราฟแนวโน้มมูลค่าสุทธิ (SVG, ไม่พึ่งไลบรารี)
js/thai-font.js       ฟอนต์ไทย (Sarabun) ฝังไว้สำหรับสร้าง PDF ที่ส่งเข้า Telegram ได้ (โหลดแบบ lazy)
js/assets.js          โมดูลทรัพย์สิน (หุ้น/ETF/คริปโต/ทอง — อัปเดตมูลค่าเอง)
js/gallery.js         แกลเลอรีไฟล์แนบ (กรอง/เรียงลำดับ/เลือกหลายไฟล์/ดาวน์โหลด/ลบ)
js/telegram.js        ส่งบันทึก/สรุปที่ไม่ใช่ส่วนตัวเข้า Telegram อัตโนมัติ
js/drive-config.js    ใส่ Google OAuth Client ID ของคุณตรงนี้
js/drive-sync.js      ซิงค์ข้อมูล+ไฟล์แนบทั้งหมดกับ Google Drive (กดปุ่มเอง, มีปุ่มรีเซ็ตการเชื่อมต่อ)
manifest.json        PWA manifest (มี share_target)
sw.js                Service worker (ใช้งานออฟไลน์ + แจ้งเตือนอัปเดตแอป)
icons/               ไอคอนแอป
```
