# my-diary

ไดอารี่ส่วนตัว — เว็บแอปแบบ local-first เขียนได้หลายรอบต่อวัน

**ฟีเจอร์หลัก**
- โหมดบันทึกส่วนตัวแบบเข้ารหัส (AES-256-GCM) ต่อ entry พร้อมคำใบ้รหัสผ่านและตัวรีเซ็ตรหัสผ่าน
- แนบรูปภาพ, บันทึกเสียง, วิดีโอสั้น (สูงสุด 30 วิ), วาดภาพ (sketch pad พร้อม undo/ยางลบ)
- จัดรูปแบบข้อความ: **ตัวหนา**, *ตัวเอียง*, บูลเล็ต, เช็คลิสต์ (แตะเพื่อติ๊กได้จริง), คำพูดอ้างอิง, โค้ดบล็อก (มีปุ่มคัดลอก, ยุบอัตโนมัติถ้ายาว), ลิงก์กดได้อัตโนมัติ, แทรกอีโมจิด่วน
- บันทึกตำแหน่ง GPS แบบไม่บังคับ พร้อมชื่อสถานที่และลิงก์เปิด Google Maps
- ปักหมุดบันทึกสำคัญ, ติดสีป้ายพาสเทล, ค้นหา/กรองตามแท็กและเดือน, ปฏิทินดูภาพรวม
- "วันนี้ในอดีต" และแบนเนอร์เตือนถ้ายังไม่ได้เขียนวันนี้
- Auto-save ร่างระหว่างเขียน (ยกเว้นบันทึกส่วนตัว เพื่อไม่ให้เก็บข้อความไม่เข้ารหัสไว้)
- หน้าสถิติ/ภาพรวม — จำนวนบันทึก, สตรีกการเขียน, อารมณ์/แท็กที่พบบ่อย
- ถังขยะ — ลบแล้วกู้คืนได้ภายใน 30 วัน ก่อนลบถาวรอัตโนมัติ (ลบถาวรแล้วซิงค์ไม่ดึงกลับมา)
- ธีม 7 แบบ + ปรับขนาดตัวอักษรได้ ในหน้าตั้งค่า
- รับข้อความ/ลิงก์จากแอปอื่นผ่าน "แชร์เข้า" และแชร์บันทึกออกเป็นข้อความ (Web Share API)
- สำรอง/กู้คืนข้อมูลทั้งหมดเป็นไฟล์ JSON (รวมไฟล์แนบ) หรือส่งออกแบบอ่านง่ายเป็น Markdown
- ซิงค์กับ Google Drive แบบกดปุ่มเอง (มี toast แจ้งสถานะระหว่างซิงค์)
- **โมดูลการเงิน (ใหม่)** — บันทึกรายรับ/รายจ่าย/โอนเงิน แยกหมวดหมู่และกระเป๋าเงินได้เอง สรุปเดือนนี้ กราฟรายเดือน+แยกหมวดหมู่ ตารางสรุปย้อนหลัง 6 เดือน — ปัจจุบันยังเป็นข้อมูล**เฉพาะในเครื่อง ไม่ได้ซิงค์กับ Google Drive**

ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ ผ่านเบราว์เซอร์ปกติ หรือติดตั้งเป็นแอป (Add to Home Screen) เพราะเป็น PWA

## เก็บข้อมูลไว้ที่ไหน

ข้อมูลทั้งหมดเก็บอยู่ใน **IndexedDB ของเบราว์เซอร์** บนเครื่องที่เปิดใช้งาน (ข้อความ + ไฟล์แนบ) ไม่มีการส่งข้อมูลไปที่ไหนโดยอัตโนมัติ โค้ดใน repo นี้ไม่มีเนื้อหาไดอารี่ของใครทั้งสิ้น — ไฟล์สำรอง (`diary-backup-*.json`, `diary-entry-*.json`) ถูกกันไว้ใน `.gitignore` ไม่ให้หลุดขึ้น repo โดยไม่ตั้งใจ

บันทึกส่วนตัว (🔒): เนื้อหา + ไฟล์แนบทั้งหมดเข้ารหัสรวมอยู่ในก้อนเดียว ด้วยกุญแจที่มาจากรหัสผ่านที่ตั้งไว้ (ไม่เคยถูกเก็บ)
บันทึกทั่วไป: ไฟล์แนบ (รูป/เสียง/วิดีโอ/ภาพวาด) เก็บแยกเป็น attachment ใน IndexedDB และเมื่อซิงค์ จะอัปโหลดเป็นไฟล์แยกบน Google Drive ของคุณเอง (มองเห็นเฉพาะไฟล์ที่แอปนี้สร้าง เพราะขอสิทธิ์แบบ `drive.file`) — ทำให้เปิดจากอีกเครื่องแล้วดึงไฟล์แนบมาได้ตามต้องการ (lazy download)

## เปิดใช้งานผ่าน GitHub Pages

1. Push โค้ดนี้ขึ้น repository บน GitHub (repo ชื่อ `my-diary`)
2. ไปที่ repo → **Settings → Pages**
3. ใต้ "Build and deployment" เลือก Source: **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ GitHub จะให้ URL ประมาณ `https://<username>.github.io/my-diary/`
6. เปิด URL นั้นบนมือถือ/คอมพิวเตอร์ แล้วกด "Add to Home Screen" (มือถือ) หรือติดตั้งผ่านไอคอนติดตั้งในแถบที่อยู่ (คอมพิวเตอร์) เพื่อใช้งานแบบแอป — ถ้าเคยติดตั้งไว้แล้วก่อนอัปเดตนี้ ให้ลบแอปเดิมออกแล้วติดตั้งใหม่ เพื่อให้ฟีเจอร์ "แชร์เข้าไดอารี่" ทำงาน (share_target ต้องติดตั้งใหม่ถึงจะรู้จัก)

## ตั้งค่า Google Drive Sync

ต้องสร้าง OAuth Client ID ของตัวเองใน Google Cloud Console (ฟรี) แล้วนำมาใส่ใน `js/drive-config.js`:

1. https://console.cloud.google.com/ → สร้างโปรเจกต์ใหม่
2. เปิดใช้งาน **Google Drive API** (APIs & Services → Library)
3. ไปที่ **Google Auth Platform** (เมนูใหม่แทน "OAuth consent screen" เดิม) → Get started → เลือก Audience: **External**
4. แท็บ **Audience** → เพิ่มตัวเองเป็น Test user
5. แท็บ **Data Access** → เพิ่ม scope `.../auth/drive.file`
6. แท็บ **Clients** → Create OAuth client → Web application → Authorized JavaScript origin ใส่ URL ของเว็บนี้ (เช่น `https://<username>.github.io`, ห้ามมี path ต่อท้าย)
7. คัดลอก Client ID มาวางแทนที่ `PASTE_YOUR_CLIENT_ID_HERE...` ใน `js/drive-config.js`
8. Push ขึ้น GitHub อีกครั้ง แล้วรีเฟรชหน้าเว็บ 2 ครั้ง (service worker ต้องอัปเดตตัวเองก่อน)

กดปุ่ม "ซิงค์ตอนนี้" ในหน้าตั้งค่าเพื่อรวมข้อมูล+ไฟล์แนบระหว่างเครื่อง

## โครงสร้างไฟล์

```
index.html          หน้าหลัก
css/style.css        ธีม/สไตล์ (4 ธีม + ปรับขนาดตัวอักษร)
js/app.js            ตรรกะหลักของแอป
js/db.js             ชั้นเก็บข้อมูล (IndexedDB: entries + attachments)
js/crypto.js          เข้ารหัส/ถอดรหัสบันทึกส่วนตัว (Web Crypto API)
js/markdown.js        จัดรูปแบบข้อความเบาๆ + เช็คลิสต์
js/theme.js           ธีม/ขนาดตัวอักษร
js/finance.js         โมดูลการเงิน (รายรับ/รายจ่าย/โอนเงิน)
js/drive-config.js    ใส่ Google OAuth Client ID ของคุณตรงนี้
js/drive-sync.js      ซิงค์ข้อมูล+ไฟล์แนบกับ Google Drive (กดปุ่มเอง)
manifest.json        PWA manifest (มี share_target)
sw.js                Service worker (ใช้งานออฟไลน์)
icons/               ไอคอนแอป
```
